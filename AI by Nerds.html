01 · The basics

So… what is AI?

Artificial intelligence is software that learns patterns from data instead of following only hand-written rules. Show it enough examples and it can recognise faces, translate languages, write text or drive a car.

Machine Learning

Algorithms that improve with experience. Instead of coding rules, we give examples and let the computer find the rules.

Deep Learning

Machine learning with many-layered neural networks, loosely inspired by brain cells.

Generative AI

Models that create new content: text, images, music, code.

Narrow vs General

Today's AI is narrow: great at specific tasks. AGI is still a research goal.

1950

Alan Turing asks "Can machines think?" and proposes the Turing Test.

1956

The term "artificial intelligence" is coined at Dartmouth.

1997

IBM's Deep Blue beats world chess champion Garry Kasparov.

2012

2017
