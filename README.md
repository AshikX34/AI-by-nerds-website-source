# 🍋 AI Explained (`AI by Nerds.html`)

An interactive, single-file web journey through the fundamentals of Artificial Intelligence, complete with live simulations, a custom local rule-engine chatbot, fully functioning minigames, and a zero-gravity physics easter egg[cite: 1]!

---

## 🚀 Features

* **Zero Build Steps:** Self-contained within a single production-ready HTML file containing all markup, styles, and logic[cite: 1].
* **Dynamic Backgrounds & Visuals:** Powered by an animated gradient canvas and a WebGL light ray renderer that tracks cursor movement[cite: 1].
* **Citrus AI (Local Rule Engine):** An interactive rule-based chat interface supporting math evaluations, unit conversions, prime checks, time/date queries, and trivia (~10 million effective pattern matches)[cite: 1].
* **Live Gradient Descent Lab:** A visual interactive demonstration of machine learning optimization and loss reduction in real time[cite: 1].
* **Interactive Code Editor:** Built-in syntax highlighting and sandbox environment supporting live JavaScript code execution and HTML/CSS previews[cite: 1].
* **Easter Eggs & Games:** Includes fully playable mini-games (Reaction Timer, Memory Match, Number Guessing, and Tic-Tac-Toe), a Konami code party mode, and a **Zero-Gravity Physics Mode** activated by clicking the footer credit button (`&`)[cite: 1].

---

## 🛠️ Built With

* **HTML5 / CSS3:** Modern layouts utilizing CSS variables, glassmorphism, fluid typography, and dark/light mode switching[cite: 1].
* **Vanilla JavaScript (ES6+):** Custom physics engine, event handlers, chat parsers, and game loops without external framework dependencies[cite: 1].
* **WebGL & Canvas API:** Custom vector math, particle networking, and background visual effects[cite: 1].

---

## 📦 Getting Started

Since this project is contained entirely in a single file (`AI by Nerds.html`), running it requires no complex installation or package managers[cite: 1]:

1. Download or clone the `AI by Nerds.html` file[cite: 1].
2. Double-click the file to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
